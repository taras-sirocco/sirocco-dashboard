# Прототипи планшетного застосунку Sirocco — складальна дільниця

Це статичні HTML-прототипи екранів. Кожен файл відкривається в браузері,
екрани інтерактивні (клікаються, працює камера/мікрофон де є).
Це НЕ фінальний код — це референс дизайну і логіки для розробки.

## Екрани

1. **01-login.html** — вхід: вибір відповідального за зміну + PIN
2. **02-opening.html** — відкриття зміни: чек-лист «так/ні» + прийняття робочого місця
3. **03-task.html** — задачі: послідовна подача, лічильник, ввід кількості
4. **04-steps.html** — інструкція по кроках (TWI) + звірка з еталонною деталлю
5. **05-close.html** — аркуш дня + закриття зміни (з фото) + екран спокою
6. **06-blocker.html** — «Що завадило?» при недосягненні цілі
7. **07-hub.html** — головний екран зміни + «що змінили» + нотатка/проблема + модалки

## Дизайн-токени

```
bg-page        #0b1020
accent         #7f77dd   (lo #544bc0 / hi #a49cf6)
text-primary   #ffffff
text-secondary #b8b2f0
danger-text    #ff9a9a
ok             #5dcaa5
warn           #ffcf5d
radius         20px
шрифт          Manrope (заміна фірмового AXIFORMA)
```

Стиль: скляні картки (glassmorphism), кольорові плями під склом, світлий кант
по периметру, високий контраст. Тексти й кнопки великі — під рукавички.

## Що ці прототипи НЕ показують

- наскрізну навігацію між файлами (кожен файл — окремий шматок)
- offline-логіку, збереження, синхронізацію
- реальні дані (усе демо, зашите в код)
- адмінку (Payload)

Логотип поки плейсхолдер (пунктирна рамка «SIROCCO») — замінюється на файл.
